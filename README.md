# Portfolio Website

This folder contains the portfolio website split into separate files.

## Files

- `index.html` — Page structure and content
- `style.css` — All CSS styles extracted from the original HTML
- `script.js` — JavaScript interactions
- `profile.png` — Profile picture
- `Pasted image.png` — Acmegrade official logo
- `abc.gif` — Animated GIF

## Run locally

The Google Fonts stylesheet still loads from Google Fonts, so an internet connection is needed for those fonts; the site itself can otherwise be opened locally.
